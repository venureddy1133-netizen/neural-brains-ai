Privacy and operating notes

The Python server binds to 127.0.0.1 and is not exposed to your local network. If Gemini is configured, the current chat message is sent from this Mac to Google; your Gemini API key stays in the local Python backend and is never sent to this page. Local SQLite memory remains on this Mac. Sharing matching memory context with Gemini is disabled by default. Google's free tier may use submitted content to improve its products, so do not send sensitive information. Browser speech recognition may also send audio to a browser provider for transcription. Wake phrase mode is phrase matching over browser-recognized speech, not a dedicated wake-word engine.
